How this demo works

The original project is a Streamlit app: an LSTM model trained on the Sentiment140 tweet dataset (79% accuracy) scores the text, and pyttsx3 speaks it on the user's computer. A trained model can't run inside a static web page, so this browser demo keeps the same thresholds and voice settings but replaces the two heavy parts:

Limitation: both versions use standard voices that can only change speed, pitch and loudness, so the emotion is suggested by prosody, not acted. Truly emotional voices need neural text-to-speech with emotion styles (for example Azure Neural TTS speaking styles such as cheerful or sad), which is the next step for this project. Voices differ a lot between browsers: in Chrome, the "Google US English" voices respond best to pitch changes.
